# inbox

Drop saved articles here and the agent reads them on its next run.

Use this for anything behind a paywall. Open the article yourself through your own
subscription or Kellogg library access, save it, and put the file here. Save as PDF,
HTML, or plain text; any of the three works.

The agent treats these as first-class sources, scored like anything it found itself,
and tiered by publisher rather than by the fact that you saved them. After a run it
moves what it consumed into `./inbox/read/` so the folder stays a queue.

Run notes at the bottom of each brief name the stories a paywall blocked. That list is
your shopping list for this folder.
